- **Live page:** https://yahya0347.github.io/hifz-privacy/
- **Source:** [`privacy-policy.md`](privacy-policy.md) · [`index.html`](index.html)

The policy is written to match what the app actually does, and should be
updated in the same change as any behaviour it describes.

## Before publishing to an app store

Two placeholders still need real values in both `index.html` and
`privacy-policy.md`:

- `CONTACT_EMAIL_HERE` — the address users should write to.
- The legal entity in the footer, if it is not exactly correct.
